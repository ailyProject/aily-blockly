This document explains the SCSS-based styling system in Aily Blockly, including the dark and light theme definitions, Blockly custom renderer themes (`aily-thrasos`), dynamic theme switching with SVG grid updates, and global component styling.

## Styling Architecture

The Aily Blockly application uses a layered styling approach. It leverages Angular's SCSS support for component-level styles while maintaining global stylesheets for theme variables and utility classes. The system is designed to support dynamic theme switching between \"Dark\" and \"Light\" modes.

## Theme Definitions (SCSS)

The system uses CSS Variables (Custom Properties) to define theme-specific colors and dimensions. The dark theme is the default, applied to `:root`, while the light theme is activated via the `[data-theme=\"light\"]` attribute.

### Dark Theme (`_dark.scss`)
The default theme optimized for long development sessions.
- **Primary Background**: `#2b2d30` [src/styles/themes/_dark.scss:5-5]()

## Blockly Custom Renderer and Themes

Blockly's visual appearance is controlled through a combination of Custom Renderers and Theme objects. Aily Blockly uses the `aily-thrasos` renderer, which extends the standard Thrasos renderer to include custom icon support.

### Custom Renderer: `aily-thrasos`
The `Renderer` class in `aily-thrasos` is responsible for the geometry and drawing of blocks. It integrates `AilyIcon` logic into the block rendering lifecycle.

## Dynamic Theme Switching

Theme switching is managed by the `ThemeService` and reflected in the `BlocklyComponent`. When the theme changes, the application updates the global `data-theme` attribute and refreshes the Blockly workspace configuration, including the SVG grid colors.

### SVG Grid and Workspace Updates
Because Blockly's grid is rendered in an SVG, its colors must be updated programmatically during a theme switch. The `blocklyGridColourForUiTheme` function determines the correct grid color based on the active `ThemeMode`.

| Theme Mode | Grid Color Variable | Value |
| :--- | :--- | :--- |
| Dark | `BLOCKLY_GRID_COLOUR_DARK` | `#3c3e41` |
| Light | `BLOCKLY_GRID_COLOUR_LIGHT` | `#d0d0d0` |

**Sources:** [src/app/editors/blockly-editor/components/blockly/theme.config.ts:87-92](), [src/app/editors/blockly-editor/components/blockly/blockly.component.ts:87-94]()

## Global Component Styling

Global styles are defined in `src/styles.scss` and include overrides for third-party libraries like Ng-Zorro-Antd and Blockly's internal UI elements.

### Blockly UI Overrides
- **Dropdown Menus**: Styled to match the IDE's menu system with custom background `var(--aily-bg-primary)` and hover states `var(--aily-menu-hover)` [src/styles.scss:182-253]().
- **Toolbox**: The native Blockly toolbox is hidden (`left: -10000px`), and its data is mirrored into the `BlocklyToolboxPaneComponent` for a more integrated look [src/app/editors/blockly-editor/components/blockly/blockly.component.scss:157-170]().

### Font System
The IDE uses a specific font hierarchy for readability and code clarity:
- **Primary**: `MiSans Regular` [src/styles.scss:11-11]().
- **Code/Monospace**: `FiraCode Regular` and `Consolas` [src/styles.scss:11-11](), [src/styles.scss:130-131]().

**Sources:** [src/styles.scss:1-272](), [src/app/editors/blockly-editor/components/blockly/blockly.component.scss:157-248]()
