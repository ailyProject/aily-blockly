The code generation system transforms visual Blockly blocks into executable Arduino C++ code and MicroPython scripts. This system handles the conversion from visual programming constructs to properly structured firmware, managing code organization, variable declarations, library imports, and hardware-specific program structures.

## Arduino Code Generator Architecture

The code generation system is built around the `arduinoGenerator` instance of the `ArduinoGenerator` class, which extends Blockly's base `CodeGenerator`. It manages the state of code sections and provides specialized methods for hardware-specific code injection.

## Code Structure Organization

The `ArduinoGenerator` maintains a `codeDict` object that categorizes generated code into distinct sections. This prevents code duplication and ensures proper Arduino program structure.

| Section | Purpose | Generated Location |
|---------|---------|-------------------|
| `macros` | Preprocessor definitions | Top of file |
| `libraries` | Include statements | After macros |
| `variables` | Global variable declarations | After includes |
| `objects` | Global object instantiations | After variables |
| `functions` | Custom function definitions | Before `setup()` |
| `setups_begin` | Early `setup()` code | Beginning of `setup()` |
| `setups` | Main `setup()` code | Middle of `setup()` |
| `setups_end` | Late `setup()` code | End of `setup()` |
| `loops_begin` | Early `loop()` code | Beginning of `loop()` |
| `loops` | Main `loop()` code | Middle of `loop()` |
| `loops_end` | Late `loop()` code | End of `loop()` |

## Block-to-Code Mapping and Traceability

To support advanced UI features like code highlighting and AI-assisted debugging, the system maintains a bidirectional mapping between visual blocks and generated code lines.

### Mapping Data Structure
The `BlockCodeMapping` interface tracks the exact line range for each block ID.
- `startLine`: The first line in the generated source code for this block.
- `endLine`: The last line in the generated source code for this block.

### Implementation in BlocklyService
The mapping is managed by `BlocklyService` using the following subjects:
- `blockCodeMapSubject`: A `BehaviorSubject` containing a `Map<string, BlockCodeMapping>` updated after every code generation cycle [src/app/editors/blockly-editor/services/blockly.service.ts:156-157]().
- `selectedBlockSubject`: Tracks the currently active block to highlight corresponding code in the viewer [src/app/editors/blockly-editor/services/blockly.service.ts:152-153]().

## ABS (Aily Block Syntax) Generator

The Aily Block Syntax (ABS) is a domain-specific language used to represent Blockly workspaces in a human-readable, indentation-based format for AI agents.

```mermaid

    subgraph \"Natural Language Space\"

    end

    LLM <-->|\"Edits\"| ABS
    ABS -->|\"parse()\"| Parser
    Parser -->|\"rootBlocks\"| ABI
    ABI <-->|\"convertAbiToAbs()\"| Converter
    Converter --> Service
```

### Key Functions
- `convertAbiToAbs()`: Converts the standard Blockly ABI JSON format into the ABS format [src/app/tools/aily-chat/tools/abiAbsConverter.ts:33-95]().
- `convertAbiToAbsWithLineMap()`: Generates ABS while also providing a mapping of block IDs to ABS line numbers, stored in `absBlockLineMap` [src/app/tools/aily-chat/tools/abiAbsConverter.ts:101-162]().
- `BlocklyAbsParser.parse()`: Converts an ABS string back into a list of `BlockConfig` objects that can be used to rebuild the workspace [src/app/tools/aily-chat/tools/absParser.ts:240-241]().

## Code Section Management Methods

The `ArduinoGenerator` provides dedicated methods to safely inject code into the final output without causing duplicates.

| Method | Target Section | Behavior |
|--------|----------------|----------|
| `addLibrary(tag, code)` | `libraries` | Adds `#include` with deduplication via `tag`. |
| `addVariable(tag, code)` | `variables` | Adds global variable declarations. |
| `addSetup(tag, code)` | `setups` | Injects code into the Arduino `setup()` function. |
| `addLoop(tag, code)` | `loops` | Injects code into the Arduino `loop()` function. |
| `addFunction(tag, code)`| `functions` | Adds top-level C++ function definitions. |
