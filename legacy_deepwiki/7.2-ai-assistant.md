The AI Assistant provides an integrated conversational interface within the Aily Blockly IDE, enabling users to receive development assistance, board recommendations, library suggestions, and interactive project guidance through natural language conversations.

The system supports two primary modes: **Agent Mode** (for interactive tool-based task execution) and **QA Mode** (for standard question-answering). It utilizes a streaming SSE architecture with Web Worker proxies to ensure a responsive UI during long-running AI generations.

## System Architecture

The AI Assistant is built on a multi-layered service architecture that separates UI state, business logic (the \"Engine\"), and communication protocols.

### Streaming SSE via Web Worker Proxy
To prevent the Angular main thread from blocking during heavy JSON parsing of AI tokens, the IDE uses a `ChatKernelProxy` [src/app/tools/aily-chat/services/chat.service.ts:48]().
- **Offloading**: Fetching and SSE parsing are moved to a Web Worker.
- **Throttling**: The `ChatViewAdapter` uses `requestAnimationFrame` (rAF) to batch UI updates, ensuring that streaming text only triggers Angular change detection once per frame [src/app/tools/aily-chat/services/chat-engine.service.ts:65-67]().

## Specialized Features

### Context Budget Monitoring
The IDE monitors the \"Context Budget\" to prevent exceeding the LLM's token limit.
- **Service**: `ContextBudgetService` tracks token usage for the current project, open files, and conversation history [src/app/tools/aily-chat/services/context-budget.service.ts:1-50]().
- **UI**: A circular token-budget-indicator in the chat input area visualizes the remaining capacity [src/app/tools/aily-chat/aily-chat.component.scss:342-365]().

### MCP Server and Tool Integration
The Assistant supports the **Model Context Protocol (MCP)**, allowing it to interact with local development tools.
- **Tool Registry**: Tools like `editBlockTool`, `webSearchTool`, and `fetchTool` are registered in the `ToolRegistry` [src/app/tools/aily-chat/services/chat-engine.service.ts:35-40]().
- **Approval System**: Sensitive operations (e.g., file deletion) trigger a `ToolApprovalRequest` requiring user confirmation in the chat UI [src/app/tools/aily-chat/services/chat-engine.service.ts:41]().

### Session and Edit Lifecycle
- **Checkpoints**: The `EditCheckpointService` allows users to \"Restore Checkpoints,\" reverting the project state to a specific point in the conversation history [src/app/tools/aily-chat/services/edit-checkpoint.service.ts:1-30]().
- **Repetition Detection**: `RepetitionDetectionService` uses KMP-based algorithms to detect if the AI is stuck in a loop (e.g., repeating the same tool call or text) and provides recovery suggestions [src/app/tools/aily-chat/services/repetition-detection.service.ts:100-113]().
