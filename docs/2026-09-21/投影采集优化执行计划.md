# 投影采集优化执行计划

## Intent：最终目标

最小范围消除 ABS 导出和草稿检查中逐字段、逐块重复全量项目快照的平方级成本。新增逻辑独立存放，保留既有加载、应用、回滚与发布流程。

## Data：可用证据

atRevision 每次都会捕获完整项目。运行时字段和过程契约遍历会反复调用该函数。现有 captureAbsWorkspaceState 已有捕获前后的工作区序列化比较。

## Edges：边界与限制

仅优化同步采集阶段；外层异步边界和提交前的完整检查保留。循环仍检查项目上下文、定义和编辑租约。返回的字段查询函数仍执行完整 revision 检查。虚拟 DOM 与 Worker 不属于本次最小改动。

自定义 getter 应是读取操作；阶段前后比较不能检测恶意回调修改后又恢复的所有中间状态，此实现不承诺对任意有副作用代码提供隔离。

## Answer：交付与成功标准

新增 abs-projection-capture.ts，仅替换协调器中的两处采集调用。运行既有相关回归测试与编译检查，不新建测试用例，不操作用户窗口。完整快照不再按采集字段及块数重复执行；所有既有回归应通过。

```mermaid
flowchart LR
    A[导出或草稿检查] --> B[完整项目基线检查]
    B --> C[同步采集：上下文及租约轻量检查]
    C --> D[原有工作区前后比较]
    D --> E[完整项目基线检查]
    E --> F[原有转换及事务发布]
```
