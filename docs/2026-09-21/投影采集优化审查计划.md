# 投影采集优化审查计划

## Intent

撤销虚拟画布改动，仅审查保留的 ABS 采集优化是否改变功能或一致性保证。

## Data

比较未提交 diff 与 HEAD，追踪两处调用方、运行时字段/过程契约采集、项目快照与 revision、定义快照、异步发布和异常释放路径；独立只读审查交叉核对。

## Edges

不顺带修改 ABS 实现，不新增测试用例、不操作 UI。区分确定的控制流变化、具有触发条件的缺陷、尚无生产实例的风险。既有回归通过不代表覆盖新增 helper。

## Answer

输出按严重程度排序的问题、定位、触发过程和修复方向，并记录撤销范围与验证结果。

```mermaid
flowchart LR
    D[两个文件diff] --> C[调用方与消费方]
    C --> G[轻量检查和完整快照对比]
    G --> E[异常及提交边界]
    E --> R[问题清单和残余风险]
```
