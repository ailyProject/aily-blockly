# 电路仿真独立窗口执行记录

## Intent：最终目标

将 aily-blockly 中电路仿真的可见界面统一为独立窗口，禁止主窗口工具面板及聊天 Dock 内嵌展示。

## Data：可用证据

### 根因

“查看电路”按钮已经选择独立窗口，但展示约束只存在于调用参数。其他入口仍能使用通用的 `embedded` 默认值；独立窗口还能通过 `embed` 回到主窗口。聊天活动有独立的 Dock 展示路径，需要共同遵守产品约束。

### 实际修改

| 文件 | 修改 |
| --- | --- |
| `src/app/configs/tool.config.ts` | 集中声明只允许独立窗口的工具集合，目前包含 Simulator；提供共享查询函数。 |
| `src/app/services/core/app-shell/ui.service.ts` | 普通打开及主窗口回流入口转向独立窗口；底层显式内嵌入口拒绝受限工具。 |
| `src/app/services/integrations/automation/main-ui-automation.service.ts` | 打开请求统一解析为独立窗口；拒绝 `embed`；能力列表移除内嵌动作。 |
| `src/app/editors/blockly-editor/services/installed-child-tool-launcher.service.ts` | 启动模式和返回模式均遵守集中策略，避免实际打开独立窗口却报告内嵌。 |
| `src/app/tools/child-tool-host/child-tool-host.component.ts` | 隐藏“放回主窗口”按钮；宿主控制方法拒绝内嵌；聊天展开请求打开独立窗口。 |
| `src/app/tools/child-tool-host/child-tool-host.component.html` | 窗口按钮绑定到策略过滤后的列表。 |
| `src/app/services/integrations/subapps/subapp-agent-bridge.service.ts` | 将受限工具的已解析界面展示请求转为独立窗口，不创建 Dock 展示。 |

## Edges：边界与限制

- 本次仅修改 aily-blockly，不依赖重新发布 Simulator 子应用来获得展示限制。
- 子应用的发现、安装、运行时连接、项目上下文、原生窗口复用与关闭生命周期继续使用原有实现。
- 规则属于宿主产品配置；入口代码按统一策略处理，不按测试数据或特定调用路径返回伪造结果。
- 不新增测试用例，不启动浏览器做 UI 确认；没有进行桌面运行态人工验证。
- 全量服务架构检查仍被上述无关问题阻断，本次未扩展修改范围。

## Answer：交付结果与自我审查

- 工具栏、应用商店等普通打开路径在进入主窗口工具栈前转向独立窗口。
- 自动化和启动器即使收到内嵌打开请求，也选择独立窗口；窗口切回内嵌请求明确失败，原窗口保持打开。
- Simulator 的“放回主窗口”按钮被移除；其他工具保留原有按钮和展示能力。
- 聊天活动展开选择独立窗口并保持 Dock 折叠。
- `presentUi: false` 或展示条件不成立时，解析结果没有展示请求，仍保持后台执行。
- 自我审查发现并移除了自动格式化引入的大量无关空行变化，将补丁收敛到展示策略及其必要调用点。
- 类型与模板检查不能代替真实桌面交互验收；当前交付为通过静态检查的源码修改，未声称已完成运行态验证。
