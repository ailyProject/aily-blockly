## 性能修复与测量

核心使用原生 `moveBefore` 移动单个 SVG 根，避免为置顶移动所有其他函数堆栈；保留不支持该 API 的浏览器回退。字段/气泡焦点样式限定到实际焦点节点，公开焦点类及键盘导航不变。拖动样式只匹配直接所属字段/图标。HTML 尺寸重置排除深层 SVG，并显式保留工作区、拖动和动画 SVG 的尺寸规则。

主窗口使用等价的 flex 容器，保留原有 content/sider 组件及面板尺寸管理，避免 `.ant-layout *` 在每个深层 SVG 节点上遍历祖先。衍生文件重试先检测活动手势/编辑器，再读取全项目 revision；没有关闭后台生成或显式保存功能。

以下为同一真实项目副本、Electron 软件渲染环境的单次采样，不能视作跨硬件的稳定中位数：

| 采样场景 | 合并兼容初稿或优化前 | 最终结果 | 验证边界 |
| --- | --- | --- | --- |
| 全局区少量块，完整 7765 块模型仍加载 | 最大长任务约 6198 ms | 379 ms；指针步骤最大 105 ms，多数 7–17 ms | 旧目标版相同场景约 339 ms，最终并非所有指标优于旧目标版 |
| loop 715 块，其他函数隐藏 | 初稿最大长任务约 613 ms | 最大长任务 353 ms、最大帧间隔约 350 ms | 与旧目标版约 353 ms 接近；仍存在起止阶段停顿 |
| 全部文件打开，含小地图就绪 | 优化前约 35.6 s | 20.8 s | 完整原生模型、代码和导航保持 |
| 整段拖动 7005 块 setup 堆栈 | 优化前约 15.4 s | 14.1 s | 位置移动 +80/+40，7765 块及代码保持；仍明显卡顿 |

少量函数连续拖拽的定时器采样没有发现重型任务在手势期间运行；代码发布的约 51–62 ms 回调在手势结束后发生。深层堆栈整段移动的剩余开销集中于样式计算、布局及重绘，不能宣称“所有大项目拖动已流畅”。
