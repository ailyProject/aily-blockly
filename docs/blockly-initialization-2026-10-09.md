# 大项目初始化与 /roots 加载失败修复（2026-10-09）

本轮使用用户确认的“岩石测量装置”，当前原项目为 7765 块、3 个根块。测试均在独立副本和独立 Electron 用户目录中进行，原项目 `project.abi` 的 SHA-256 在验证后保持不变。另用历史扩展的 8265 块项目回归深链交互。

## 已复现的加载失败

原生反序列化完成后，编辑器会等待一帧，让评论图标及气泡坐标恢复，再执行持久化状态读回校验。这个间隙原先允许工作区接收输入。在真实 Electron 加载流程的该边界派发 pointerdown/move/up，可以拆出子块，随后稳定得到用户报告的两条错误：

- `AbsSyncError: Blockly changed or discarded persisted state at /roots.`
- `Unable to open the requested project: Error: 加载项目失败：Blockly changed or discarded persisted state at /roots.`

修复在反序列化到读回准入之间持有既有工作区编辑租约，取消已有手势、隔离鼠标和键盘编辑，并在 `finally` 释放。读回以同一个租约所有者读取完整文档。没有忽略 `/roots`、排序掩盖差异或关闭数据完整性检查。已验证同一竞争输入被阻止，3 个根块保持一致，加载正常完成；完成后恢复正常编辑。

这是本轮实际复现的触发路径，不据此认定所有未来的 `/roots` 错误都来自用户拖动。真实丢块、连接变化、字段拒绝等仍会阻止加载。

## 初始化工作量调整

- 视口索引仍覆盖全部模型，离屏块不再先全量重挂 SVG、写入变换后又立即移除。只为实际选中的可见视图执行这些操作，按绘制顺序批量插入，避免完整导出时反复扫描所有兄弟节点。
- Aily 装饰图标有明确尺寸，其图片、字体和 SVG 内容延迟到首次可见时创建。滚动、聚焦、完整导出、删除动画和关闭虚拟化分别处理内容补全；删除或替换图标会取消待执行任务。
- 变量菜单按当前名称与 ID 的完整快照复用排序，每次仍检查真实列表。改名、删除、新建、允许类型和潜在变量变化会失效，返回独立菜单数组。
- 字段恢复通过 `get()` 自带的完整定义检查读取声明，去掉紧邻的重复检查。定义被回调改动的情况仍有回归测试。

按需加载的是显示内容，块模型、连接、字段值、序列化及代码生成仍完整。未实现“先接受缺失模型、随后后台补块”。主题、字体和块尺寸规则未改动。

## 同配置加载对照

Electron 35.7.5 / Chromium 134，GPU compositing 为 enabled；同一 7765 块副本、完整主软件配置、`aily-thrasos`、开启虚拟化和小地图，各运行四轮。基线恢复之前实际安装的 `9691554019cf` 核心包及旧图标/字段排序代码；加载租约保护两组均开启，避免竞态影响性能采样。

| 原生加载中位数 | 6.204 s | 4.131 s（减少 33.4%） |
| 原生加载范围 | 5.889–6.678 s | 4.068–4.185 s |

| 原生加载后挂载块数 | 58 | 58 |
| 延后创建图标内容的块数 | 0 | 7438 |

“完整就绪”包含路由、库加载、工作区读回、运行时 ready 和两帧等待；首轮还采集 CPU profile，存在模块加载等波动。它不是单独测量首个绘制像素，也不是安装程序冷启动时间。用户仍可能看到数秒加载等待，不能据此宣称已经没有卡顿。

CPU 采样中重复声明完整性检查的自身耗时约从 1480 ms 降到 750 ms，变量排序的约 756 ms 热点消失。剩余开销包含文字样式测量、模型布局、祖先渲染排队和主程序初始化；本轮保留真实 CSS/字体测量，没有通过换主题隐藏开销。

证据目录：`e2e/.artifacts/blockly-initialization-2026-10-09/aily-baseline` 与 `aily-optimized`，含逐轮结果、GPU 状态和 CPU profile。早期精简配置未启用 Aily 渲染器，其结果不作为以上对照依据。
