# 开发板配置子菜单错配修复

## 现象与入口

用户视频 `c5f554846ab6817f03b05e2389762edc.mp4`：从 USB 模式移到闪存模式后，子菜单位置跟随鼠标，但仍显示 Hardware CDC and JTAG / USB-OTG，旧项高亮也未同步消失。

正式入口为 `HeaderComponent.openPortList()` → `getDevicePortList()` → `ProjectService.getBoardConfigMenu()` → `app-menu.ports.main-menu-parity`。修复位于主软件共用的 `src/app/components/menu/MenuComponent`，不涉及 Aily Chat 子应用或开发板配置值。

## 原因与处理

- 定位使用零延时定时器和 `ngAfterViewChecked` 两条路径。定时器可先于合并后的 Angular 渲染执行，测量旧 DOM，并把旧选项在新锚点标记为可见。新增回归在原代码下稳定得到“Hardware CDC and JTAG 不包含 QIO 80MHz”的失败。
- 对框架外创建菜单、监听器在 Angular zone 外执行的情况，原逻辑仅修改普通属性，没有显式请求渲染；界面可能保持旧内容。真实开发窗口的内存样例也复现了状态变化而 DOM 不刷新的情况。
- 悬停切换与关闭明确调用 `markForCheck()`，只在 `ngAfterViewChecked` 中测量并显示已渲染的新内容，移除竞争定时器。关闭流程统一清理选中项、定位状态、模型浮层标记与待关闭定时器；禁用项不展开子菜单。
